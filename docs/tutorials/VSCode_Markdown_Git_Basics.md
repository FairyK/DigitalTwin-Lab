1. 首选：Visual Studio Code（强烈推荐）

数字孪生学习后面一定会用：

Python
UE
Isaac Sim
ROS2
Git
Docker
YAML配置
JSON数据

所以 VS Code 基本是必备工具。

下载：

Visual Studio Code 官方网站

安装时建议：

勾选：

☑ Add to PATH
☑ Add "Open with Code" action
☑ Register Code as an editor
2. 用 VS Code 创建 Markdown 文件

例如项目：

DigitalTwin-Lab
│
└── docs
    │
    └── learning-log

打开：

VS Code

↓

文件

↓

打开文件夹

↓

选择：

DigitalTwin-Lab

然后：

右键：

learning-log

选择：

New File

输入：

Day001.md

注意：

一定要包含：

.md

不要创建：

Day001.md.txt
3. 安装 Markdown 插件

VS Code 左侧：

扩展：

搜索：

Markdown All in One

安装。

作用：

自动目录
快捷键
格式优化

再安装：

Markdown Preview Enhanced

作用：

可以预览效果。

4. 创建后的效果

文件：

Day001.md

# Day001学习记录

## 今日学习

计算机基础

WebSocket

然后点击右上角：

预览按钮
