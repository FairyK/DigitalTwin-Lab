## 二、今日完成内容

### 1. Function 输入参数

创建：

`SetMotorTemperature`

添加 Input：

```text
NewTemperature : Float
```

Function 内部逻辑：

```text
Function Entry
      ↓
Set Temperature
```

其中：

```text
NewTemperature
      ↓
Temperature
```

因此可以调用：

```text
SetMotorTemperature(100)
```

让当前 Motor 的 Temperature 变成 100。

---

### 2. Function + Object Reference

继续使用：

```text
Motor_01
   ↓ TargetMotor
Motor_02
```

Motor_01 通过 `TargetMotor` 找到 Motor_02，然后调用：

```text
SetMotorTemperature(100)
```

结果：

```text
Motor_02.Temperature = 100
```

这进一步说明：

> Reference 用来找到具体对象，Function 用来让这个对象执行行为。

---

### 3. Function 返回值

给 `SetMotorTemperature` 添加 Output：

```text
ResultTemperature : Float
```

执行过程：

```text
输入 NewTemperature
        ↓
Set Temperature
        ↓
Get Temperature
        ↓
ResultTemperature
```

因此调用 Function 后，不仅可以“让对象做事情”，还可以把结果返回给调用者。

今天实际测试成功：

```text
SetMotorTemperature(85)
        ↓
ResultTemperature = 85
        ↓
Print String
        ↓
屏幕显示 85
```

---

### 4. StartMotor / StopMotor

创建两个 Function：

#### StartMotor

```text
Set Running = true
        ↓
Set RPM = 1500
```

#### StopMotor

```text
Set Running = false
        ↓
Set RPM = 0
```

这两个 Function 分别代表电机的两个行为：

```text
StartMotor()
StopMotor()
```

---

### 5. Branch + Boolean

学习了：

```text
Branch
```

Branch 根据 Boolean 条件决定执行哪条路线：

```text
          Condition
              ↓
           Branch
          /      \
       True      False
        ↓          ↓
      执行A       执行B
```

使用：

```text
Get Running
     ↓
Branch
```

测试成功：

- Running = true → `Motor Running`
- Running = false → `Motor Stopped`

## 三、今天建立起来的整体认识

目前 `BP_Motor` 已经不再只是一个“带变量的模型”。

它开始具有：

```text
BP_Motor
│
├── 数据 / 状态
│   ├── Temperature
│   ├── RPM
│   └── Running
│
├── 行为 / Function
│   ├── SetMotorTemperature()
│   ├── StartMotor()
│   └── StopMotor()
│
├── 对象关系
│   └── TargetMotor
│
└── 决策
    └── Branch
```

这是从“会使用 UE”向“开始进行 UE 编程”的重要一步。
