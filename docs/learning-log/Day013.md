## 二、核心知识：三种数据形态

| 类型 | 含义 | 示例 |
|---|---|---|
| `dict` | Python 程序内部的数据结构 | `{"rpm": 1200}` |
| `str` | 文本字符串，JSON 可用这种形式传输 | `'{"rpm":1200}'` |
| `bytes` | 字节序列，网络消息载荷常见的形式 | `b'{"rpm":1200}'` |

基本转换：

```python
import json

data = {"device_id": "Motor01", "rpm": 1200}

json_text = json.dumps(data)       # dict → JSON str
data_again = json.loads(json_text) # JSON str → dict

payload = json_text.encode("utf-8")       # str → bytes
text_again = payload.decode("utf-8")      # bytes → str
```

注意：`json.dumps()` 负责序列化，`json.loads()` 负责解析。接收 MQTT 消息时，通常先对 `msg.payload` 解码，再调用 `json.loads()`。

## 三、定义统一的数据契约

Python、MQTT 接收程序和 UE 必须约定相同的字段与类型。

示例消息：

```json
{
  "schema_version": 1,
  "device_id": "Motor01",
  "timestamp": "2026-10-20T21:00:00+08:00",
  "sequence": 12,
  "rpm": 1200,
  "temperature": 63.5,
  "running": true,
  "fault": false
}
```

字段说明：

| 字段 | 类型 | 作用 |
|---|---|---|
| `schema_version` | 整数 | 数据结构版本 |
| `device_id` | 字符串 | 设备标识，必须与 UE Map 的 Key 一致 |
| `timestamp` | 字符串 | 数据产生时间，建议带时区 |
| `sequence` | 整数 | 单台设备递增序号，用于辅助检测重复或乱序 |
| `rpm` | 数值 | 转速，单位 r/min |
| `temperature` | 数值 | 温度，单位 ℃ |
| `running` | 布尔值 | 是否运行 |
| `fault` | 布尔值 | 是否故障 |

关键原则：

1. `device_id` 是字符串标识，不是 UE Actor Reference。
2. JSON 中的 `true`、`false` 对应 Python 的 `True`、`False`。
3. 转速应是数值 `1200`，而不是字符串 `"1200"`。
4. 时间戳是设备数据产生的时间，不一定等于 UE 收到数据的时间。
5. 每台设备单独维护 `sequence`。
6. 数据必须先校验，再更新 UE 状态。

将以下代码放入 `day013_json_simulator.py`：

```python
import json
import time
from datetime import datetime, timezone, timedelta

BEIJING_TZ = timezone(timedelta(hours=8))

motors = {
    "Motor01": {
        "rpm": 1200,
        "temperature": 42.0,
        "running": True,
        "fault": False,
        "sequence": 0,
    },
    "Motor02": {
        "rpm": 0,
        "temperature": 28.0,
        "running": False,
        "fault": False,
        "sequence": 0,
    },
}


def make_motor_message(device_id, state):
    state["sequence"] += 1

    return {
        "schema_version": 1,
        "device_id": device_id,
        "timestamp": datetime.now(BEIJING_TZ).isoformat(
            timespec="seconds"
        ),
        "sequence": state["sequence"],
        "rpm": state["rpm"],
        "temperature": round(state["temperature"], 1),
        "running": state["running"],
        "fault": state["fault"],
    }


def simulate_step(state):
    # 这是用于验证数据链路的简单模拟规则，不是真实电机物理模型。
    if state["running"] and not state["fault"]:
        state["temperature"] = min(
            state["temperature"] + 0.3, 95.0
        )
    elif not state["running"]:
        state["temperature"] = max(
            state["temperature"] - 0.2, 20.0
        )


def main():
    try:
        while True:
            for device_id, state in motors.items():
                simulate_step(state)
                message = make_motor_message(device_id, state)

                json_text = json.dumps(
                    message,
                    ensure_ascii=False,
                    separators=(",", ":"),
                )

                print(f"[{device_id}] {json_text}")

            print("-" * 60)
            time.sleep(1)

    except KeyboardInterrupt:
        print("\n模拟器已停止。")


if __name__ == "__main__":
    main()
```

```powershell

```

停止程序：按 `Ctrl+C`。

- 运行中的电机温度逐渐上升，停止中的电机温度逐渐下降。
- 输出内容是 JSON 文本。

## 六、实验 3：实现数据校验函数

把下面的函数添加到模拟器文件中，放在 `main()` 函数之前：

```python
def validate_motor_message(message):
    required = {
        "schema_version",
        "device_id",
        "timestamp",
        "sequence",
        "rpm",
        "temperature",
        "running",
        "fault",
    }

    if not isinstance(message, dict):
        return False, "消息根节点必须是 JSON object"

    missing = required - message.keys()
    if missing:
        return False, f"缺少字段: {sorted(missing)}"

    if message["schema_version"] != 1:
        return False, "不支持的 schema_version"

    if message["device_id"] not in {"Motor01", "Motor02"}:
        return False, "未知 device_id"

    rpm = message["rpm"]
    if isinstance(rpm, bool) or not isinstance(rpm, (int, float)):
        return False, "rpm 必须是数值"

    temperature = message["temperature"]
    if isinstance(temperature, bool) or not isinstance(
        temperature, (int, float)
    ):
        return False, "temperature 必须是数值"

    sequence = message["sequence"]
    if isinstance(sequence, bool) or not isinstance(sequence, int):
        return False, "sequence 必须是整数"

    if not isinstance(message["running"], bool):
        return False, "running 必须是布尔值"

    if not isinstance(message["fault"], bool):
        return False, "fault 必须是布尔值"

    if rpm < 0:
        return False, "rpm 不能小于 0"

    if not -20 <= temperature <= 200:
        return False, "temperature 超出实验允许范围"

    if sequence < 0:
        return False, "sequence 不能小于 0"

    if not isinstance(message["timestamp"], str):
        return False, "timestamp 必须是字符串"

    if not message["timestamp"]:
        return False, "timestamp 不能为空"

    return True, "OK"
```

测试数据：

```python
valid_message = {
    "schema_version": 1,
    "device_id": "Motor01",
    "timestamp": "2026-10-20T21:00:00+08:00",
    "sequence": 1,
    "rpm": 1200,
    "temperature": 63.5,
    "running": True,

## 七、实验 4：模拟网络接收端解析数据

在已经定义好 `valid_message` 和 `validate_motor_message()` 的测试环境中运行：

import json

json_text = json.dumps(valid_message)

# 模拟网络库接收到字节载荷

# 接收端：bytes → str → dict
received_text = payload.decode("utf-8")
received_message = json.loads(received_text)

ok, reason = validate_motor_message(received_message)

if ok:
    print("消息通过校验：", received_message["device_id"])
else:
    print("拒绝消息：", reason)
```

## 八、故障排查

| 问题 | 可能原因 | 处理方式 |
|---|---|---|
| `python` 命令不可用 | Python 未安装或 PATH 未配置 | 试试 `py --version` |
| `JSONDecodeError` | JSON 文本不合法 | 检查引号、逗号和原始字符串 |
| 布尔值校验失败 | 写成了 `"True"` 字符串 | 使用 Python `True`，JSON 中对应 `true` |
| 设备被判定为未知 | `device_id` 拼写或大小写不一致 | 对照设备登记表和 UE Map Key |
| 序号每次从 1 开始 | 状态被重复初始化 | 每台设备持续保存自己的序号 |
| 数值校验失败 | 数字被误写成字符串 | 检查数据源字段类型 |
