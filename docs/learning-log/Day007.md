# 二、理论知识

## 2.1 JSON 是什么

JSON 是一种用于不同程序之间交换结构化数据的文本格式。

Python 中可以使用字典表示电机数据：

```python
data = {
    "device_id": "Motor01",
    "rpm": 1500,
    "temperature": 63.5,
    "running": True
}
```

JSON 的形式与 Python 字典很相似：

```json
{
    "device_id": "Motor01",
    "rpm": 1500,
    "temperature": 63.5,
    "running": true
}
```

JSON 的意义在于：

> Python、C++、Java、JavaScript、UE 等不同程序可以使用统一的数据格式进行数据交换。

---

## 2.2 json.dumps()

```python
json.dumps(data)
```

作用：

> **把 Python 对象转换成 JSON 字符串。**

例如：

```python
data = {
    "device_id": "Motor01",
    "temperature": 63.5
}

message = json.dumps(data)
```

转换关系：

```text
Python dict
    ↓
json.dumps()
    ↓
JSON string
```

转换之后：

```python
type(data)
```

是：

```text
dict
```

而：

```python
type(message)
```

是：

```text
str
```

因此 `dumps` 可以理解成：

> **把 Python 中的数据“打包成 JSON 文本”。**

---

## 2.3 json.loads()

当程序从网络或 MQTT 收到 JSON 字符串后，需要把它重新解析成 Python 数据。

```python
message = '{"device_id": "Motor01", "temperature": 63.5}'

data = json.loads(message)
```

转换关系：

```text
JSON string
    ↓
json.loads()
    ↓
Python dict
```

之后就可以：

```python
print(data["temperature"])
```

得到：

```text
63.5
```

因此：

```text
发送方向：

Python dict
    ↓ dumps
JSON string
    ↓ 网络 / MQTT
    ↓
JSON string
    ↓ loads
Python dict
```

# 三、MQTT 基础

## 3.1 MQTT 是什么

MQTT 是一种轻量级的消息通信协议。

它的核心模式不是：

```text
Python → UE
```

而是：

```text
Publisher
    ↓
MQTT Broker
    ↓
Subscriber
```

Broker 负责消息中转。

---

## 3.2 Mosquitto 是什么

MQTT 是通信协议。

Mosquitto 是一个实际运行 MQTT Broker 的软件。

可以理解为：

```text
MQTT
=
通信规则

Mosquitto
=
按照 MQTT 规则运行的 Broker 软件
```

本次实验已经完成：

* 安装 Mosquitto
* 启动 MQTT Broker
* 使用本机 MQTT 服务进行通信测试

---

# 四、MQTT 核心角色

## 4.1 Publisher

Publisher 负责：

> 发布消息。

例如 Python 模拟 Motor01：

```text
Motor01
 ↓
Python
 ↓
Publisher
 ↓
发送温度数据
```

---

## 4.2 Broker

Broker 是消息中转站。

例如：

```text
Python Publisher
        ↓
   MQTT Broker
        ↓
Python Subscriber
```

Publisher 不需要直接知道 Subscriber 在哪里。

Broker 负责将消息转发给符合订阅条件的客户端。

---

## 4.3 Subscriber

Subscriber 负责：

> 订阅自己关心的 Topic。

例如：

```python
client.subscribe(
    "factory/motor/Motor01/state"
)
```

表示：

> 我希望接收 `factory/motor/Motor01/state` 这个 Topic 的消息。

---

## 4.4 Topic

Topic 可以理解成 MQTT 中的“消息频道”。

例如：

```text
factory/motor/Motor01/state
```

还可以设计：

```text
factory/motor/Motor01/temperature
factory/motor/Motor01/rpm
factory/motor/Motor02/state
```

Topic 的设计可以帮助系统区分：

* 哪个工厂
* 哪种设备
* 哪个设备
* 哪种数据

---

# 五、Paho MQTT Python 客户端

使用：

```python
import paho.mqtt.client as mqtt
```

Paho MQTT 是 Python 的 MQTT 客户端库。

---

## 5.1 创建 MQTT Client

```python
client = mqtt.Client()
```

表示：

> 创建一个 MQTT 客户端对象。

这个 Client 负责与 MQTT Broker 建立连接，并进行发布、订阅和消息处理。

可以理解成：

```text
Python程序
    ↓
MQTT Client
    ↓
MQTT Broker
```

---

## 5.2 连接 Broker

```python
client.connect("localhost", 1883, 60)
```

三个参数：

```text
localhost
    ↓
本机

1883
    ↓
MQTT Broker 的端口

60
    ↓
连接保持相关的 keepalive 参数
```

因此：

```python
client.connect("localhost", 1883, 60)
```

可以理解为：

> 连接本机 `localhost` 上 1883 端口运行的 MQTT Broker。

# 六、MQTT 回调机制

MQTT 实验中第一次接触了一个重要的编程思想：

> **事件发生 → 自动调用对应的回调函数。**

---

## 6.1 on_connect

首先定义：

```python
def on_connect(client, userdata, flags, rc):
    print("MQTT连接成功")
```

然后：

```python
client.on_connect = on_connect
```

意思不是立即执行 `on_connect()`。

而是：

> 告诉 MQTT Client：以后连接成功时，调用 `on_connect`。

流程：

```text
client.connect()
    ↓
Broker 接受连接
    ↓
连接成功
    ↓
触发 on_connect()
    ↓
执行函数中的代码
```

因此可以在 `on_connect()` 中进行 Topic 订阅。

---

## 6.2 on_message

定义：

```python
def on_message(client, userdata, msg):
    print("收到消息")
```

然后：

```python
client.on_message = on_message
```

意思：

> 告诉 MQTT Client：以后收到消息时，调用 `on_message`。

流程：

```text
Broker
 ↓
收到新的 Topic 消息
 ↓
MQTT Client
 ↓
触发 on_message()
 ↓
处理消息
```

---

# 七、MQTT 消息对象

在：

```python
def on_message(client, userdata, msg):
```

中：

```text
msg
```

代表当前收到的 MQTT 消息。

---

## 7.1 msg.topic

```python
msg.topic
```

表示：

> 当前消息来自哪个 Topic。

例如：

```text
factory/motor/Motor01/state
```

---

## 7.2 msg.payload

```python
msg.payload
```

表示：

> 当前消息真正携带的数据。

MQTT 接收到的 payload 通常是 bytes。

例如可能表现为：

```text
b'{"temperature": 63.5}'
```

---

## 7.3 msg.payload.decode()

```python
msg.payload.decode()
```

作用：

> 把 bytes 解码成字符串。

因此：

```text
msg.payload
    ↓
bytes
    ↓ decode()
JSON string
```

然后再：

```python
json.loads(message)
```

就可以变成 Python dict。

完整过程：

```text
MQTT消息
 ↓
msg.payload
 ↓
bytes
 ↓
.decode()
 ↓
JSON字符串
 ↓
json.loads()
 ↓
Python dict
```

---

# 八、client.loop_forever()

```python
client.loop_forever()
```

作用：

> 让 MQTT Client 持续运行并不断处理 MQTT 网络通信和事件。

如果没有持续运行：

```text
连接 Broker
 ↓
订阅 Topic
 ↓
程序立即结束
```

那么程序就没有机会持续接收后续消息。

有了：

```python
client.loop_forever()
```

之后：

```text
程序持续运行
    ↓
等待 MQTT 消息
    ↓
收到消息
    ↓
触发 on_message()
    ↓
处理消息
    ↓
继续等待
    ↓
……
```
